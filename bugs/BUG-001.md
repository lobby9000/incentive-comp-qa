| Reported by | Luis A. Quiroz |

## Steps to reproduce

1. Create seller `S00001` in store `T1000`.
2. `POST /imports/transactions` with a SALE `I-1` of 300.00 and a RETURN `I-2` of 100.00 that references `I-1`.

## Expected result

201 with `{"imported": 2, "sales": 1, "returns": 1, "credits": 2}`.

## Actual result

500 Internal Server Error with a plain-text body. Server log: `AttributeError: 'list' object has no attribute 'original_transaction_id'` in `app/service.py`, `build_transaction`.

## Impact

Any realistic batch fails, because returns are about 5.5% of the rows. The full dataset could not be loaded through the import endpoint, which blocked the parallel run. Workaround used for rc1: load with one `POST /transactions` per row (25,259 calls).
