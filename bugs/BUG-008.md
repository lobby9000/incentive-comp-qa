## Steps to reproduce

1. Run the API with `DATABASE_URL=postgresql+psycopg://...`.
2. Create seller `S00001`.
3. Post any SALE with credits.

## Expected result

201 with the credit lines.

## Actual result

500. Log: `psycopg.errors.ForeignKeyViolation: insert or update on table "credit" violates foreign key constraint "credit_transaction_id_fkey"`.

## Impact

The production database rejects every sale and return. The functional suite passed on SQLite because SQLite does not enforce foreign keys unless `PRAGMA foreign_keys=ON` is set, so the defect was invisible there.
