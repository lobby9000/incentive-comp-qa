## Steps to reproduce

1. Post a SALE of 10,000.00 split 70/30 (S00001, S00002).
2. Post a RETURN of 100.01 for it inside the window.

## Expected result

-70.01 for S00001 and -30.00 for S00002 (magnitudes use the sale rule, then are negated).

## Actual result

-70.00 for S00001 and -30.01 for S00002.

## Impact

The return still nets to -100.01, but each seller's statement is off by one cent. In the dataset: 171 seller statements with a credited amount off by 0.01, one of which also changes the payout by 0.01.
