# BUG-005 Odd-cent clawback on a split return moves one cent between the sellers

|---|---|

| Requirement | REQ-RET-04 |
| Found by | TC-RET-004, TC-REC-001 |
| Environment | Build 0.1.0-rc1 (tag v0.1.0-rc1), Python 3.13, FastAPI 0.143, SQLModel 0.0.48, Ubuntu 24.04 |
| Reported by | Luis A. Quiroz |

## Steps to reproduce

1. Post a SALE of 10,000.00 split 70/30 (S00001, S00002).
2. Post a RETURN of 100.01 for it inside the window.

## Expected result

-70.01 for S00001 and -30.00 for S00002 (magnitudes use the sale rule, then are negated).

## Actual result

-70.00 for S00001 and -30.01 for S00002.

## Impact

The return still nets to -100.01, but each seller's statement is off by one cent per return. In the dataset: 171 seller statements with a wrong credited amount (162 of them only because of this defect, off by 0.01 to 0.05), and 2 payouts changed by 0.01.

## Root cause

The split is computed with floor division on the negative amount: `floor(-10001 * 30 / 100) = -3001`, not `-3000`.

Fix: `f85f88a`.

## Verification

TC-RET-004 passes. SQL invariant TC-DB-003 (floor rule on returns) returns 0 rows on the full dataset.
