## Steps to reproduce

1. Create seller `S00001` and a 2026-10 quota of 100,000.00.
2. Post a SALE of 49,995.00 dated 2026-10-01.
3. `GET /periods/2026-10/sellers/S00001/statement`.

## Expected result

`attainment_pct` "50.00" (display only), `qualified` false, `payout` "0.00". REQ-CAL-03 evaluates the gate on the exact value (49.995%).

## Actual result

`qualified` true and `payout` "499.95". The same happens with 49,999.99, which pays 500.00.

## Impact

Any seller between 49.995% and 50% is paid as if they passed the gate. In the dataset: 1 statement (boundary seller S19002) overpaid by 499.95.

Pending developer analysis.
