# BUG-006 Displayed attainment and band commissions use banker's rounding on ties

| Field | Value |
|---|---|
| Severity | S3 Minor |
| Priority | Medium |
| Status | Closed (verified) |
| Affects version | 0.1.0-rc1 |

| Component | Statements |
| Requirement | REQ-CAL-06, REQ-STM-03 |
| Found by | TC-CAL-010, TC-CAL-014, TC-CAL-015 |
| Environment | Build 0.1.0-rc1 (tag v0.1.0-rc1), Python 3.13, FastAPI 0.143, SQLModel 0.0.48, Ubuntu 24.04 |
| Reported by | Luis A. Quiroz |

## Steps to reproduce

1. Quota 100,000.00, credited 12,345.00: get the statement (attainment 12.345%).
2. Quota 10,000.00, credited 5,000.50: get the statement (attainment 50.005%, band A commission 50.005).

## Expected result

`attainment_pct` "12.35" and "50.01". Band A `commission` "50.01".

## Actual result

"12.34", "50.00" and "50.00".

## Impact

Display only: the statement a seller reads disagrees with the plan's rounding rule on ties. Tracked apart from BUG-003 because it does not change the money, although the cause is the same.

## Root cause

Same default rounding context as BUG-003, through `quantize` for attainment and `format(value, '.2f')` for band values.

Fix: `c4bf627`.

## Verification

TC-CAL-010, TC-CAL-014 and TC-CAL-015 pass.
